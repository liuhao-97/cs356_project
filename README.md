# Vitis-AI ResNet18/50 on Cifar100 dataset, Resnet20 on Cifar10 dataset

This is the CS356 project.
The aim is to deploy ResNet18/50 on Cifar100 dataset, Resnet20 on Cifar10 dataset on Alevo U55C DPU with Vitis-AI.
Also we compare the performance of resnet20 DPU accelerator with FPGA accelerator, and the related codes are in hls4ml folder.
